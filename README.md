# 帝国时代4 · 资讯台（第一版原型）

一个纯静态 HTML 的《帝国时代4》信息站原型，无需构建工具，双击 `index.html` 即可在浏览器中打开。

## 目录结构
```
aoe4-hub/
├─ index.html            # 入口（单页应用，Tab 切换）
├─ assets/
│  ├─ css/style.css      # 样式（深色中世纪主题）
│  └─ js/
│     ├─ data.js         # 全部数据（资讯/补丁/文明/活动/天梯/电竞）
│     └─ app.js          # 渲染与交互逻辑
└─ README.md
```

## 数据说明
- 数据整理自 ageofempires.com 官网新闻、官方支持站（活动日历/天梯赛季/已知问题）与官方论坛，更新日期 2026-08-15。
- 补丁平衡数据覆盖近三个月：16.1.10056（5/11）、16.2.10604（6/1）、16.2.10884（6/17）、16.3.11214（7/2）、16.3.11308（7月）。
- 所有条目均附官方原文链接，可点击跳转核对。
